# 辽东烽烟 · 1619

一款纯前端回合制策略战棋网页游戏，背景设定在 **1619 年萨尔浒战败后的辽东**。玩家扮演大明辽东守军，在后金的持续攻势下稳住防线，寻机反攻；朝鲜为大明盟友，蒙古诸部观望守土。城池与相对方位依辽东历史形势图排布，含辽西走廊、辽河套、建州山地与朝鲜湾。

## 运行方式

- 单文件静态页面，无需安装、无需构建、不依赖任何外部 CDN 或网络。
- 直接用浏览器打开 `index.html` 即可游玩；也可部署到 GitHub Pages 等任意静态托管。

## 势力

| 势力 | 配色 | 定位 | 说明 |
| --- | --- | --- | --- |
| 大明 | 红 | 玩家 | 辽东守军，城池众多，需要防守辽阳、广宁等要点 |
| 后金 | 金 | AI | 骑兵为主，主动向辽东明军城池推进、先歼城上守军再占城，战力最强，都城赫图阿拉，唯一主动募兵的势力 |
| 蒙古诸部 | 绿 | AI 中立 | 观望守土，不主动进攻大明与朝鲜，仅在遭遇来敌时防守反击 |
| 朝鲜 | 蓝 | AI 盟友 | 与大明互不攻击，被动驻防，战力最弱 |

**阵营关系**：大明与朝鲜互为同盟，互不攻击；蒙古对大明、朝鲜保持中立观望；后金与其余三方交战，是主要进攻方。

**战力排序**：后金（攻击/士气/防御/反击加成最高）> 大明（基准）> 蒙古（偏弱）> 朝鲜（最弱）。

**战斗交换比**：后金防御与反击系数更高，同兵种、同兵力明军主动攻坚后金属劣势交换——典型步兵接战后金军损约一半、明军折损约四分之三；反过来后金进攻明军则占优。

## 玩法规则

- 每回合按 **大明 → 后金 → 蒙古 → 朝鲜** 顺序行动。
- 点击己方单位选中：蓝色格为可移动范围，红色格为可攻击目标。
- 地形影响移动消耗与防御：山地、关隘防御加成；骑兵在平原、草原战力提升，在山地折损；河流不可通行处受阻；海域不可进入。
- 每支部队每回合可移动一次、攻击一次，支持先移动再攻击；攻击后本回合行动结束。
- 走错位置可点「撤回移动」退回上一步出发位置，重新移动；若进城易帜，撤回后城池归属一并还原；结束回合后不可跨回合撤回。
- 歼守军只是扫清城上之敌，城池仍归原主；须派部队进入城池格才算占领易帜；同盟、中立城池不会被易帜；在己方城池消耗粮草招募新兵。
- 骑兵、火器仅可在重镇招募：喀尔喀、广宁、辽阳、沈阳、赫图阿拉、平壤、界凡城；其余城池只能招募步军、弓兵（AI 募兵同此限制）。
- 每座己方城池每回合提供粮草补给；右侧「+1000 粮草」按钮可随时为大明调拨补给。
- 仅后金 AI 会主动募兵扩军（野战军保持约 10 队，损员后再补），并主动进攻交战城池；蒙古、朝鲜不主动出击、不主动募兵。

## 胜负条件

- **大明胜利**：攻破后金都城赫图阿拉；或坚守至第 24 回合仍保有辽阳；或后金诸城尽失。
- **大明失败**：辽阳或广宁被后金攻占；或大明城池全部失守。

## 技术说明

- 原生 HTML / CSS / JavaScript，单文件自包含。
- 大明、后金、蒙古、朝鲜四方兵像头像均以 base64 内嵌，离线可用，画风统一为冬日辽东油画立像。
- 网格地图、BFS 移动范围、近战与远程结算、士气与地形修正、贪心 AI 均在浏览器本地运行，数据不出本机。
